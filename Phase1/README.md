# ⚾ 숫자야구 (Number Baseball)

파이썬 `tkinter`로 만든 GUI 숫자야구 게임입니다.
KDT 빅데이터/AI 부트캠프 12기 · 파이썬 프로그래밍 과정 미니프로젝트 01 (개인 프로젝트)

- **개발 기간**: 2026.01.07 ~ 2026.01.09
- **작성자**: 박성훈
- **사용 기술**: Python, tkinter, random

## 게임 규칙

- 컴퓨터가 0~9 중 **서로 다른 숫자 4개**를 정답으로 정합니다.
- **10번**의 시도 안에 정답을 맞히면 승리입니다.
- 판정 방식
  - **Strike**: 숫자와 위치가 모두 맞음
  - **Ball**: 숫자는 맞지만 위치가 다름
  - **Out**: 맞는 숫자가 하나도 없음
- 4 Strike가 되면 정답입니다.

## 실행 방법

Python 3과 표준 라이브러리 `tkinter`가 필요합니다. 별도 설치할 패키지는 없습니다.

```bash
python number_baseball.py
```

> 화면 글꼴로 `함초롱바탕`을 지정했습니다. 없는 환경에서는 다른 글꼴로 표시될 수 있습니다.

## 화면 구성

- 상단: 시도 기록 로그 (`회차. 입력값 | strike / ball / out`)
- 중단: 현재 입력 중인 4자리, 직전 시도의 Strike / Ball 수
- 하단: 0~9 숫자 버튼 (클릭으로 입력)

## 코드 구조

| 함수 | 역할 |
|---|---|
| `push_button(num)` | 버튼 입력 처리. 중복 숫자 차단, 4자리가 차면 판정 호출 |
| `judge(guess, target)` | 입력값과 정답을 자리별로 비교해 ball / strike / out 계산 |
| `log(guess_list, b, s, o)` | 시도 결과를 화면에 한 줄씩 기록하고 남은 횟수 차감 |
| `update_guess_labels(guess_list)` | 입력한 숫자를 `_` 자리에 표시 |
| `reset_labels()` | 새 시도가 시작되면 입력 표시를 초기화 |
| `game_end(s)` | 승리 / 패배 안내창을 띄우고 창 종료 |

## 구현 포인트

- `random.sample`로 중복 없는 4자리 정답 생성
- 버튼 10개를 반복문으로 생성하고, `lambda n=num`으로 각 버튼에 자기 숫자를 연결
- 이미 입력한 숫자를 다시 누르면 안내창을 띄우고 입력을 무시
